# WorkLock

Фото-заставка для Fedora 43 / GNOME 49 (Wayland). Показывает выбранное изображение поверх рабочего стола на подключённых мониторах. Нажатие клавиши или щелчок мышью открывает поле пароля; верный пароль убирает заставку. Приложения под ней продолжают работать.

**Это не блокировка безопасности.** WorkLock не перехватывает системные клавиши, переключение окон, виртуальных рабочих столов или доступ через другие сеансы. Для защиты компьютера используйте штатную блокировку GNOME.

## Запуск из исходников

Нужны Python 3, PyGObject, GTK 4 и libadwaita. В каталоге проекта:

```sh
python3 -m worklock
```

Выберите фото, задайте и подтвердите пароль, нажмите «Показать заставку». Пароль действует только для текущего показа и не сохраняется. После разблокировки его нужно ввести заново. Путь к фото и настройка предотвращения сна сохраняются в `~/.config/worklock/settings.json`; содержимое файла не содержит пароль. Если предотвращение сна не поддерживается сеансом, заставка всё равно запускается.

## RPM

На Fedora с `rpm-build`:

```sh
./scripts/build-rpm.sh
```

Исходный архив, RPM и SRPM появятся в `dist/`. Установить собранный RPM можно через `sudo dnf install ./dist/worklock-0.1.1-1*.noarch.rpm`; затем запускать `worklock` из меню приложений или терминала.

Готовый RPM доступен на [странице последнего релиза](https://github.com/ShafranovKirill/WorkLock/releases/latest).

## Ограничения

При подключении и отключении мониторов WorkLock старается обновить окна заставки. Wayland и GNOME могут разрешать системное переключение окон и рабочих столов; непрерывное перекрытие всех экранов не гарантируется. При принудительном завершении процесса заставка исчезает. Фотографии остаются по исходным путям и не копируются в конфигурацию.
